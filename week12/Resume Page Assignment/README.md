# HTML Resume Page Assignment

This is my submission for the **Web Dev Cohort 2026** (Week 12). The objective was to build a single-page resume website matching a specific layout using **only HTML** (no CSS).

## 🛠️ Tech Stack

- **HTML5** (Semantic Tags, Tables for layout)
- **No CSS** (Styling achieved via HTML attributes like `border`, `width`, etc.)

## 📝 Features

- **Pure HTML Structure:** Uses semantic tags (`<header>`, `<section>`, `<table>`, `<hr>`) to maintain readability.
- **Table-Based Layout:** Utilizes HTML tables to replicate the grid alignment for the "Education" sections.
